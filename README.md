# Jing Dong Product Leader Portfolio

> Executive Product Leader Personal Brand Website

这是一个面向产品负责人个人品牌展示的网站，用于呈现产品经验、业务案例、产品思考以及 AI 时代的创造方式。

## Overview

这是一个 Executive Portfolio Website，面向希望快速理解产品领导力、复杂项目经验与协作方向的读者：

- CEO
- Founder
- Hiring Manager
- Product & Technology Leaders

核心表达：

> 连接商业、技术与 AI，推动复杂产品从 0 到 1 落地。

网站以发布会式叙事组织内容，而非将经历堆叠为普通简历或作品列表。

## Design Philosophy

项目采用 **Executive Presentation Design**：以克制的视觉层级、清晰的内容节奏和高质量资产表达产品领导力。

视觉体系：

- Black Gold
- Luxury Editorial
- Founder Portfolio
- Premium Product Storytelling

设计与实现遵循以下路径：

```text
Design Reference
        ↓
Visual Asset Extraction
        ↓
React Semantic Layer
        ↓
Internationalization
```

图片承担背景、光效、抽象系统与空间氛围；React 承担内容结构、SEO 语义、i18n 和响应式布局。因此，视觉表现与中英文内容可以独立维护。

## Development Approach

本项目采用 **AI-assisted Product Development Workflow**，将设计资产、语义内容与前端实现保持在同一套可复用流程中：

```text
Design Reference
        ↓
Asset Analysis
        ↓
Asset Manifest
        ↓
Visual Asset Extraction
        ↓
React Implementation
        ↓
International QA
```

该流程让每个页面既能贴近设计稿，又能保持可维护的组件结构、多语言内容和响应式体验。

## Project Structure

```text
src/
├── components/  # Reusable UI components
├── pages/       # Page-level structures
├── assets/      # Production visual assets
└── locales/     # Internationalization resources
```

`components` 负责跨页面复用的界面结构；`pages` 组织页面级叙事；`assets` 管理从设计稿拆分出的生产视觉资产；`locales` 维护中英文内容资源。

## Design System

全站采用 **Black Gold Executive System**，统一管理以下表达规则：

- Typography
- Spacing
- Visual Assets
- International Layout Rules

中文排版遵循设计稿的视觉比例；英文在不影响阅读与版式稳定性的前提下使用独立字号与换行规则。

## AI Workflow

### AI-Assisted Creation Process

本项目探索如何使用 AI 辅助完成：

- 页面概念设计
- 视觉资产拆分
- 前端实现
- 多语言适配

AI 用于提升从设计理解到实现验证的效率；内容语义、页面结构和产品叙事仍保持清晰、可维护且适合真实业务沟通的标准。
